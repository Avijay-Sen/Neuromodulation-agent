# Research Backlog

Queue of candidate neuromodulation startups for future daily batches
(~5/day). When the daily automation runs, it should:

1. Pick the next ~5 `[ ]` (not yet researched) entries below, keeping a
   reasonable mix across categories (don't do 5 from the same category in a
   row unless the queue forces it).
2. Research each with the same rigor as the initial 15 (see `README.md` →
   "Per-startup fields" and "Data sources / methodology").
3. Add a full profile under `docs/profiles/<category>/<slug>.md`.
4. Add a row to `data/neuromodulation_startups.xlsx` (master sheet + the
   relevant category sheet).
4. Check the box below `[x]` and log the batch in `CHANGELOG.md`.
5. If the queue runs low (<10 unresearched entries left), use web search to
   identify and append new credible candidate companies before finishing the
   batch, keeping the category balance (cognitive / mental health /
   neuro-musculoskeletal / sleep apnea) roughly even over time.
